About moteroon

moteroon is a private, self-hosted automation tool developed and operated by an individual creator in Japan. It is used solely to manage the creator's own content workflow across TikTok, YouTube Shorts, and Instagram Reels — all from a single creator account (@moteroon_jp).

The application is not a public service, marketplace, or platform for other users. It exists only to streamline the creator's own daily publishing schedule and analytics review.

What It Does

📅 Scheduled Publishing

Uploads pre-rendered short videos (1080×1920, ≤60s) to the creator's own TikTok account at scheduled times to maintain a consistent daily posting cadence.

📊 Analytics Review

Fetches public statistics (views, likes, comments) on the creator's own videos for content performance review.

🔒 Single-Account Use

The application authenticates with the creator's TikTok account only. No third party users, no shared infrastructure, no end-user signup.

🛠️ Local Operation

All credentials and data are stored locally on the developer's own machine. No external server, database, or third-party data sharing.

TikTok API Usage

moteroon integrates with TikTok's official APIs in the following ways:

  • Content Posting API (video.publish) — Publishes pre-rendered MP4 files produced by the creator's own video rendering pipeline.
  • Display API (video.list) — Retrieves the creator's own video metadata to populate a local analytics dashboard.
  • Login Kit (user.info.basic) — Authenticates the creator's own TikTok account via OAuth 2.0 + PKCE.

All API requests use only the creator's own OAuth token. The application does not act on behalf of, or transmit data of, any other TikTok user.
