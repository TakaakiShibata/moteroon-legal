Privacy Policy

Effective Date: May 14, 2026
Last Updated: June 11, 2026

1. Introduction

This Privacy Policy explains how moteroon (the "Application", "we", "us", or "our") collects, uses, stores, and protects information when the Developer uses the Application. The Application is a private automation tool used exclusively by its sole Developer to publish original short video content to the Developer's own social media accounts on TikTok, YouTube, and Instagram.

2. Scope and Applicability

This Privacy Policy applies only to data processing by the Application itself. It does not apply to:

  • How TikTok collects or processes data (see TikTok's Privacy Policy)
  • How YouTube collects or processes data (see Google's Privacy Policy)
  • How Instagram collects or processes data (see Instagram's Privacy Policy)

3. Information We Collect

The Application collects and processes only the minimum data necessary to function. Specifically:

4. Information We Do NOT Collect

The Application does not collect, process, or store any of the following:

  • Data about any TikTok user other than the Developer
  • Personal information of any third party
  • Device identifiers, IP addresses, or precise location
  • Biometric, financial, or government identification information
  • Browsing or behavioral tracking data

5. How We Use Information

The information collected is used exclusively for:

  • Authenticating API requests to TikTok using the Developer's own credentials
  • Uploading the Developer's own pre-recorded video content to the Developer's own TikTok account
  • Fetching and locally displaying public statistics of the Developer's own videos for personal performance review

No information is used for advertising, profiling, machine learning training, or any commercial purpose beyond the Developer's own content management workflow.

6. Data Storage and Security

All data, including OAuth access and refresh tokens, is stored locally on the Developer's personal computer. Specifically:

  • Tokens are stored in encrypted JSON files within the Application's local working directory
  • The Developer's computer is protected by operating system user account controls and full disk encryption
  • No data is stored on any external server, cloud database, or remote infrastructure operated by the Developer
  • All API communication uses HTTPS / TLS 1.2+ encryption

7. Data Sharing and Disclosure

We do not sell, trade, lease, share, or otherwise transfer any data to third parties. Data is transmitted only to TikTok's official API endpoints (and the equivalent endpoints of YouTube and Instagram) as necessary to provide the Application's functionality. No data is shared with advertisers, analytics providers, or any other third party.

9. User Rights

As the sole user of this Application, the Developer has full and immediate control over all data, including the right to:

  • Revoke API access at any time via TikTok's settings page
  • Delete the local credential files at any time
  • Stop using the Application at any time

Because the Application processes no third-party data, no other persons are involved in or affected by data subject rights.

10. Children's Privacy

The Application is not intended for, and not made available to, children under the age of 13. The Developer is over the age of 18. No data of any child is collected.

11. International Data Transfers

When the Application transmits data to TikTok's API endpoints, that data may be processed on TikTok's servers located outside Japan, including in Singapore, the United States, and other jurisdictions. By using the Application, the Developer consents to such transfers, which occur strictly as necessary to use TikTok's services.

12. Cookies and Tracking

The Application is a local script-based tool and does not use cookies, tracking pixels, browser fingerprinting, or any web tracking technologies.

13. Security Incident Response

In the event of a credential compromise (e.g., the Developer's machine is lost or stolen), the Developer will:

  1. Revoke all OAuth tokens via the TikTok app settings
  2. Delete the local credential files
  3. Re-generate fresh credentials before resuming use of the Application
