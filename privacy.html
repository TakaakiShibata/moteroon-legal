Privacy Policy

Last updated: May 14, 2026

1. Overview

moteroon is used exclusively by its developer and does not collect, store, or share personal data from any third-party users.

2. Information We Collect

The application accesses the following data through TikTok's API:

  • TikTok account access token (stored locally on the developer's device only)
  • Basic profile information required for API authentication

3. How We Use Information

The access token is used solely to authenticate API requests to post videos to the developer's own TikTok account. No data is shared with third parties.

4. Data Storage

Access tokens are stored locally on the developer's device and are not transmitted to any external servers other than TikTok's official API endpoints.

5. Third-Party Services

This application uses TikTok's Content Posting API. Please refer to TikTok's Privacy Policy for information on how TikTok handles data.

6. Data Retention

Access tokens are retained until they expire or are manually deleted by the developer.

7. Children's Privacy

This application is not intended for use by individuals under the age of 13.

8. Changes to This Policy

This Privacy Policy may be updated at any time.
